# Seyro is now Jiyda

Seyro was renamed to **Jiyda**. Development continues at **https://github.com/chatyev/jiyda**.

This repository only exists so that Seyro 0.5.0 can update itself: its updater looks for new
versions here. The release below is the regular Jiyda installer under Seyro's old file name.

- **Using Seyro 0.5.0?** Just wait for the **Update** banner (or run *Check for updates* from the
  command palette). Seyro updates to Jiyda by itself and keeps your pages, Spaces and logins.
- **New install?** Download Jiyda from https://github.com/chatyev/jiyda/releases.
